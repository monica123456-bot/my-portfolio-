# Responsive Notes

## Breakpoints Tested

- **Mobile:** 375px
- **Tablet:** 768px
- **Desktop:** 1280px

The website was tested at all three breakpoints using the browser's device toolbar. The layout was checked for horizontal scrolling, overlapping content, readable text, navigation, and the contact form.

### Flexbox vs. CSS Grid

Flexbox is used to arrange and align the navigation links and allow them to wrap when necessary. CSS Grid is used in the Technical Skills section to arrange HTML, CSS, and JavaScript into responsive columns.

### Tailwind CSS Utilities

Tailwind utility classes are used in the header and Contact section. The `md:` responsive variant adjusts horizontal padding on medium and larger screens. Custom CSS handles the general styling, Flexbox, CSS Grid, and media queries.
